## Core law

`REUSE > CONNECT > REPAIR > BUILD`

For every historical day/capability, compare against current canonical state and assign exactly one outcome:

- `NO_CHANGE_REQUIRED` — current canonical state is equivalent or better;
- `REUSE_AS_IS` — historical capability remains directly valuable and already canonical;
- `CONNECT` — useful capability exists but is not wired into the canonical owner;
- `PORT_SELECTIVELY` — historical implementation has unique value absent from canonical code;
- `REPAIR` — current canonical capability violates a demonstrated invariant;
- `GOVERNANCE_ONLY` — scientific negative, supersession, authority or provenance belongs only in project memory;
- `PARK` — potentially useful but not required to close the engineering project;
- `RETIRE_FROM_ACTIVE_SCOPE` — adds no current value and should not drive future work;
- `UNKNOWN_DECISION_RELEVANT` — only when the uncertainty can change one of the decisions above.

No branch is selected wholesale because it is newer or historically important.

## Project closure definition

Engineering/project work can be considered closed for normal operation when:

- every required capability has one canonical owner in `code/canonical` or `project/canonical`;
- no decision-relevant historical capability remains unclassified;
- exact-head canonical qualification is green;
- required runtime/deployment seam is either proven or explicitly bounded as a single remaining operational block;
- authority remains fail-closed;
- negative/superseded scientific memory is durable;
- the next work items are predominantly economic/scientific rather than architecture/governance reconstruction.

Branch deletion is NOT part of this closure gate and remains `PARK` per Owner instruction.

## Economic transition rule

- economics / scientific evidence first;
- engineering only when a demonstrated economic experiment requires a missing capability or a canonical invariant fails;
- no new platform layer, scheduler, research OS, governance framework or architecture campaign without a concrete economic blocker.
