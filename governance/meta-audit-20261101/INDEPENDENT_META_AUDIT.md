## A. Executive verdict

Quant-Trade's recurring failure was incomplete capitalization of work: construction became local test evidence, sometimes a remotely qualified component, but too often failed to become recoverable bytes, a canonical owner, an integrated execution path and demonstrated use. Its memory problem was frequently routing and transport, rather than absence of historical documentation. September's organizational audit already identified truthful historical surfaces masquerading as current instructions. October's WP2 and PR46 episodes show a harder failure: knowing a local SHA and test count could not recover missing implementation bytes. [E01,E03,E08,E09]

There is no defensible global fraction of necessary work versus waste. Commits, read objects, historical active days and elapsed wall time have different denominators; none measures labor. The strongest avoidable losses are identifiable episodes: unavailable review subjects, duplicate local implementations, incomplete transport, stale instruction reuse and repeated reconciliation across disconnected branches. Their total hours and proportion of the entire project are UNKNOWN. Ranking these mechanisms is a judgment about recurrence and consequence, not a measured cost allocation.

The project also repeatedly protected itself correctly. Reviews exposed mutable receipt aliasing, incomplete execution/fixture binding, schema false-PASS paths, timing and multiplicity defects, and an unconnected host entry point after component tests had passed. Negative economic results, refusal to rerun consumed trials and source-access BLOCKs are not wasted research. Removing these controls would shorten the record while degrading its truth. The existing schema suite was executed during this mission: 15 malformed cases rejected, one complete synthetic control accepted. This checks schema behavior, not the historical restricted host receipt. [E02,E07–E10,E13]

The forensic process performed useful independent recovery, but was inefficient in several specific ways. CP11 cleanup needed CP12 correction before unique semantics could be discarded. Surface closure needed later discussion-level qualification of WP2. Coverage counts added an overlapping baseline rather than taking an identity union. Multiple navigation layers retained incompatible instructions. After decision-relevant closure, exhaustive reading continued as a separate coverage mission; the latest batch explicitly changes no current product decision. This is permissible historical work, but its current engineering value is unproven. It must not become a prerequisite for host proof. [E04–E06,E11,E12]

The audit eventually learned a better method: preserve exact identities and bytes; use chronology as an index; compare capability owners and diffs; descend only on a falsifiable decision question; distinguish scientific, engineering and runtime claims; checkpoint bounded work; preserve supersessions; and stop. A repository-only succession actually demonstrated recovery without restarting. Weekly deep reconstruction ended without proving a historical port necessary. That supports selective reading and a small handoff, not another memory platform. [E03,E05,E06]

Current truth supersedes the historical convergence prescription. `code/canonical@13c9ff03f0898e9af28abaa3dab78a520c70c887` already contains the Wave2-derived candidate and selected CP099/GIGA-Q/PR46 seams. Its hosted run `41265514716` succeeds. Recreating that candidate would be stale restart. Actual host state and real unattended multi-wake operation remain unproven. Global mission selection after a fixed task is a distinct parked limitation. Science is presently frozen by a direct Owner instruction; economic focus means reaching the authorized engineering exit without substituting more architecture or premature experiments. [E07,E10]

From now on: one current project router, one canonical owner per capability, a byte-verifiable continuation record, bounded falsification on the correct subject, and one critical-path action. Recover existing capabilities before building. Park unaffected lanes when access is missing. Do not simplify causal identity, irreversible exposure accounting or the distinction between hosted qualification and actual use.

## H. Counterfactual minimal path from first forensic day

Only process knowledge is carried back. No future conclusion, branch selection or defect is assumed known.

1. **Preserve first.** Capture refs including PR-only refs and notes, verify non-shallow objects, inventory expiring external artifacts, publish recoverable archive and a short cursor. Keep the expensive preservation step: deleting it risks permanent loss and denominator blindness.
2. **Frame current decisions.** Resolve current authority and product objectives. Create a small question list: which code root retains capabilities, which scientific claims survive, which runtime claims are demonstrated, what blocks the next action? Do not begin by reading every documentary version.
3. **Index once.** Reuse raw inventory/chronology. Hash-deduplicate; keep separate surface, direct semantic, equivalent-byte and unavailable sets. Preserve collection dates and live-ref changes. Eliminates repeat inventory safely because the original objects and delta checks remain.
4. **Compare candidate owners before deep reading.** Use ancestry, file/blob crosswalk and real entrypoint traces. Divergence is a question, not proof of missing capability. This could detect a base-selection risk without foreknowing Wave2's superiority.
5. **Challenge decisive claims.** For each favorable result ask for one specific falsifier: stale SHA, missing invocation, mutable receipt, consumed outcome, impossible denominator. Deep-read the relevant diff/test/comment; leave unrelated versions indexed. Removing this expensive stage would allow false PASS.
6. **Resolve current canonical delta.** Reuse/connect/repair on one recoverable candidate; one builder, distinct bounded challenger where required. Confirm source identities before review; don't launch an inaccessible review. Recheck only changed semantics and required regression envelope.
7. **Checkpoint by decision/delta.** At interruption publish exact subject, proven state, evidence pointer, blocker, next action and authority. Weekly checkpoints remain useful for long reading; do not require a second full narrative with identical rules.
8. **Stop archaeology when decisions stabilize.** Preserve contradiction triggers. Qualify integrated software, then actual non-economic host path. A blocked host lane stays blocked while permitted documentary repair proceeds; more historical reading does not unblock it.

## M. Required challenge of this report

Criticism revised: zero historical ports from weekly deep reading does not prove it was waste; it can establish non-loss and reveal governance corrections. Counterfactual skips only redundant rereading, not preservation or targeted falsification. Owner pauses and usage limits are not classified as avoidable auditor misconduct. CP12 challenge prevented potentially destructive premature cleanup; its cost cannot be treated as pure waste.

Praise bounded: weekly handoffs and exact-SHA rules are not automatic speed or quality. Succession supplies a behavioral success example; the host seam supplies a counterexample to component qualification. EDGE-FLOW is a direct instruction and shows useful method, but reported later stalls falsify the claim that a written continuation rule alone creates autonomy.

Forgotten-path recovery rejected where current value is absent: no WP2 rebuild, PR32 wholesale import, Weather resurrection or CP099 repeat. Current canon already subsumes selected semantics. Unknown historical details remain valid unknowns.

Simplification constrained: bypassing exposure accounting, causal subject matching, runtime proof, reviewer independence at decisive gates or immutable negative memory could allow false PASS. A rigid maximum of two rounds cannot suppress new material evidence. Exact-code tests need not be rerun solely for a documentary handoff, but the new metadata must never claim an old run occurred on the documentation commit.

This meta-audit itself risks duplicate retrospection: a cumulative report already exists. Its added value is independent separation of project/process, verification of the current snapshot, correction of the latest union, and a bounded counterfactual. It does not authorize another standing audit program.

## N. The five Day-1 rules
