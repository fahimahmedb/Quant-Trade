## Temporary isolated-science boundary

A real scientific result may precede full canonical autonomy only when the run is an isolated deterministic execution of an already frozen experiment and preserves all of these conditions:

1. candidate/experiment identity and preregistration exist before outcome observation;
2. source observations satisfy declared PIT/availability rules;
3. raw receipts, hashes, source timestamps and local capture timestamps are durable;
4. universe, frequency, horizon, transformation, parameters, costs and stop/kill/promote criteria are frozen;
5. exact code SHA and environment identity are recorded;
6. execution is deterministic/reproducible from the frozen inputs;
7. evaluator/adjudicator cannot adapt the frozen hypothesis from protected outcomes;
8. confirmation independence is not inferred from producer identity or structural tokens alone;
9. retries, prior variants, exposure and multiplicity append to the denominator instead of resetting it;
10. result identity and scientific-memory record are immutable and linked to the same experiment lineage.

## Claims explicitly forbidden from the isolated run

The isolated run cannot prove: canonical autonomous proposal/task materialization, lease/retry/recovery, Oracle continuity, unattended replenishment, runtime deployment, release promotion, live execution quality, capital readiness or economic portfolio value.

## Required later autonomy replay

After the canonical autonomy chain is qualified, replay the same frozen protocol and the exact same frozen input dataset through task -> lease -> runner -> evaluator -> scientific sink. Bind protocol hash, raw-data hashes, code/release SHA, evaluator version and output hash. Equal deterministic outputs establish integration equivalence only; the replay is not a new independent scientific trial. New observations require a new declared trial and denominator entry.

## Why this boundary is defensible

The repository already separates pure research-selection/scientific contracts from scheduler/runtime mechanics. Scientific validity turns on pre-outcome identity, PIT, provenance, frozen analysis, outcome isolation, adjudication and denominator integrity. Scheduler provenance is essential to an autonomy claim, but it is not evidence that a frozen hypothesis was fairly or unfairly tested.
