# DECISION GATES

## GATE_SCIENTIFIC_VALIDITY
REQUIRED_EVIDENCE=Frozen hypothesis/estimand/protocol before protected outcomes; valid PIT source observations; exact code/environment; deterministic execution; declared cost screen; outcome-isolated evaluation/adjudication; denominator/multiplicity append; immutable result+memory lineage.
ALLOWED_UNKNOWNS=Future economic value; full scheduler autonomy; formal release promotion; live fill quality.
HARD_STOP=Outcome-informed protocol mutation; invalid PIT/source; hidden prior exposure; confirmation independence fabricated; result cannot be linked to frozen identity.
NEXT_AUTHORIZED_ACTIONS=Record KILL/PARK/INCONCLUSIVE/bounded scientific promotion; proceed to economic transport only under a new gate.

## GATE_AUTONOMY
REQUIRED_EVIDENCE=One exact identity-conserving task->lease/retry/recovery->runner->evaluator->scientific-sink route; idempotent crash/replay; receipts and no duplicate trial/exposure.
ALLOWED_UNKNOWNS=Whether the hypothesis is positive; economic usefulness; capital readiness.
HARD_STOP=Identity loss; retry creates new trial invisibly; missing receipt concealed as success; authority upgrade.
NEXT_AUTHORIZED_ACTIONS=Same-dataset integration replay; bounded seam repair if a specific gap is proven.

## GATE_PROMOTION
REQUIRED_EVIDENCE=Owner-selected candidate SHA; mandatory gate policy; exact local PASS; exact hosted PASS; remote/tested SHA equality; explicit promotion decision; installed/runtime identity if deployment claimed.
ALLOWED_UNKNOWNS=Scientific edge; future economic value.
HARD_STOP=Branch-label authority; candidate/tested/head collapse; waived unexplained mandatory failure; install inferred from CI.
NEXT_AUTHORIZED_ACTIONS=QUALIFIED_NOT_PROMOTED or explicit promotion/release step under authority.

## GATE_REAL_EXPERIMENT
REQUIRED_EVIDENCE=Named predeclared witness; lawful source/action authority; valid source contract; PIT/frequency/universe/provenance; outcome-neutral quality checks and stop conditions.
ALLOWED_UNKNOWNS=Result sign; future replication result; portfolio value.
HARD_STOP=Source substitution changes semantics; protected outcome accessed before freeze; invalid capture.
NEXT_AUTHORIZED_ACTIONS=Execute isolated deterministic run or record PARK_DATA/BLOCK_AUTHORITY.

## GATE_MEMORY_DENOMINATOR
REQUIRED_EVIDENCE=Stable trial/root/variant IDs; prior known exposures; retries/duplicates/parks/blocks/nulls/results separately accounted; append-only memory/result links; historical UNKNOWN explicitly bounded.
ALLOWED_UNKNOWNS=Unrecoverable old trials when documented as UNKNOWN rather than zero.
HARD_STOP=Fresh cohort/name resets exposure; fabricated historical denominator; negative/data-block conflation.
NEXT_AUTHORIZED_ACTIONS=Append current trial; reconcile recoverable crosswalks without rewriting history.

## GATE_ECONOMIC_TRANSPORT
REQUIRED_EVIDENCE=Scientifically eligible result; lossless identity/authority/provenance envelope; supported expression semantics; explicit unsupported-state handling; no invented price/cashflow/correlation fields.
ALLOWED_UNKNOWNS=Actual economic success; capacity until next gate.
HARD_STOP=Claim upgrade; expression mistranslation; required market variable fabricated.
NEXT_AUTHORIZED_ACTIONS=Shadow/evaluation transport only; open economic-validation protocol.

## GATE_ECONOMIC_VALIDATION
REQUIRED_EVIDENCE=Frozen OOS/prospective economic protocol; after-cost returns; venue/instrument costs; capacity/depth/impact; benchmark; exposures/correlation; uncertainty; multiplicity/selective-search accounting.
ALLOWED_UNKNOWNS=Live execution slippage beyond observed/calibrated envelope; future regime behavior.
HARD_STOP=Use of in-sample tuning data as independent validation; cost/capacity omitted; portfolio contribution inferred from standalone Sharpe.
NEXT_AUTHORIZED_ACTIONS=Reject/park or qualify for prospective operational observation; never jump directly to capital.

## GATE_PROSPECTIVE
REQUIRED_EVIDENCE=Forward information cutoff; frozen model/protocol; real observations arriving after freeze; no outcome-conditioned retuning; timestamp/provenance continuity.
ALLOWED_UNKNOWNS=Future sample size until predeclared stopping rule resolves it.
HARD_STOP=Retrospective data presented as prospective; clock/source revision ambiguity.
NEXT_AUTHORIZED_ACTIONS=Continue to frozen stop rule; record null/negative/positive outcome.

## GATE_RUNTIME
REQUIRED_EVIDENCE=Exact installed release SHA; configuration/policy identity; restart/lease/recovery receipts; observed current process/runtime identity; no production mutation outside grant.
ALLOWED_UNKNOWNS=Scientific/economic success.
HARD_STOP=Installed version unknown; CI equated with deployment; stale branch name treated as runtime truth.
NEXT_AUTHORIZED_ACTIONS=Bounded pilot/observation under explicit operational authority.

## GATE_CAPITAL
REQUIRED_EVIDENCE=All earlier applicable gates; explicit capital authority; validated economic edge after realistic costs/capacity; portfolio risk/exposure constraints; execution/risk kill controls; prospective evidence adequate for the declared allocation policy.
ALLOWED_UNKNOWNS=Normal future market uncertainty within predeclared risk limits.
HARD_STOP=Any missing authority; no after-cost validation; no capacity/risk evidence; research PASS used as trading authorization.
NEXT_AUTHORIZED_ACTIONS=Only the separately authorized bounded allocation/pilot. Current Pass B authorizes none.
