# CAN SCIENCE PRECEDE FULL AUTONOMY?

CAN_REAL_SCIENCE_PRECEDE_FULL_AUTONOMY=YES_CONDITIONALLY

A first real scientific milestone can use an isolated deterministic execution harness while the canonical autonomous task/lease/runner/evaluator/sink chain remains incomplete, because scientific validity is a property of the frozen question, observations, provenance, deterministic transformation, evaluation/adjudication and exposure accounting—not of the scheduler that invoked the computation.

## Scientific guarantees that remain valid

Only if all are preserved:

1. experiment/candidate identity and predeclaration precede outcome observation;
2. source observations satisfy the declared PIT/availability rules;
3. raw/source receipts, hashes and timestamps are retained;
4. parameters, universe, horizon, rule, costs and stop/kill/promote criteria are frozen;
5. code/environment identity is recorded and execution is deterministic/reproducible;
6. evaluator/adjudicator is prevented from adapting the hypothesis to the observed outcome;
7. denominator, prior exposures, retries and multiplicity are recorded rather than reset;
8. result and memory identities are immutable and linked to the same lineage.

## Autonomy claims forbidden

Such a harness may **not** establish:

- autonomous end-to-end research;
- canonical proposal->task materialization;
- lease/retry/recovery correctness;
- Oracle/runner/evaluator/sink continuity;
- unattended continuation/replenishment;
- runtime/deployment readiness;
- code promotion or installed-release identity.

## Required later replay through canonical autonomy

After the autonomous chain is qualified, replay the **same frozen protocol and same frozen input dataset** through the canonical task/lease/runner/evaluator/sink path as an integration-equivalence witness. Bind protocol hash, data/raw hashes, code/release SHA, evaluator version and result hash, and compare deterministic outputs. This replay proves autonomy/integration equivalence; it must not be silently counted as a new independent scientific trial. If new observations are used, they are a new declared trial and must enter the denominator.

## Provenance links that must survive

PREDECLARATION_COMMIT/HASH -> PROPOSAL/CANDIDATE_ID -> EXPERIMENT_ID -> SOURCE_RECEIPTS/RAW_HASHES/TIMESTAMPS -> FROZEN_PROTOCOL_HASH -> EXECUTION_CODE_SHA/ENVIRONMENT -> EVALUATOR/ADJUDICATOR_ID -> RESULT_HASH -> DENOMINATOR/TRIAL_ENTRY -> SCIENTIFIC_MEMORY_RECORD_ID.

## Admissible result classes

- `PARK_DATA` / `CAPTURE_INVALID` when observations fail the contract;
- `KILL` for the exact frozen hypothesis/expression when predeclared kill conditions are met;
- `PARK` / INCONCLUSIVE when evidence is insufficient;
- bounded `PROMOTE` only within the predeclared claim ceiling when promote criteria are met.

No result from the isolated harness may be relabeled as proof of autonomy, runtime readiness, formal promotion, capital readiness or live trading.

## Why canonical autonomy is not a scientific prerequisite

The audited repository itself separates pure research selection (`research_chain.py`: no scheduler mutation/outcome access/persistent-memory write) from task/refill/Oracle execution. That architecture is compatible with scientific and autonomy evidence being separately qualified. Requiring scheduler provenance for *scientific validity* would add a property unrelated to whether the frozen hypothesis was fairly tested; scheduler provenance matters instead to the autonomous-system claim.
