# Independent authority model

The current user task authorizes audit artifacts and their local Git commit. It explicitly prohibits real source access and execution. Root contract E28 maintains economic/prospective/capital/trading authority closed absent a separate decision. Historical grants in E11/E12 are scoped evidence, not transferable authorization for a successor. Audit judgment never issues Owner authority.

| Action | Distinct object and limit | Current audit scope |
|---|---|---|
| DECLARE_TRIAL | Register unique immutable protocol, lineage and information set; no data access implied | Not granted for a real successor |
| READ_LIVE_SOURCE | Specific endpoint, fields, host, budget, window, custody, exposed identity | Prohibited |
| EXECUTE_EXPERIMENT | One frozen calculation/acquisition transaction with stop/retry law | Prohibited |
| ACCESS_RESULT | Named readers and explicit dataset/outcome/result scope; protected outcomes separate | Historical published evidence only; protected access prohibited |
| WRITE_RESULT_RECEIPT | Immutable typed result/partial/failure receipt; not scientific conclusion or memory | No production write |
| APPEND_TRIAL_EXPOSURE | Append all attempts, including partial and zero-valid; no deletion/reopen | No production append |
| WRITE_SCIENTIFIC_MEMORY | Convert accepted result into durable lesson/priority update under approved schema | Prohibited production mutation |
| RUN_AUTONOMY_REPLAY | Explicit synthetic/sandbox replay scope, state boundaries and persistence | No production replay grant; audit component tests only |
| OWNER_PROMOTE_CODE | Named Owner promotes exact product identity | Not granted |
| DEPLOY | Host/configuration/install/restart scope and rollback | Prohibited |
| REAL_CAPITAL | Specific capital allocation/risk authority | Prohibited |
| LIVE_TRADING | Venue/account/order/risk limits | Prohibited |

One future bounded experiment needs a reviewed vector covering declaration, source, execution, result access, receipt and exposure writes; it may explicitly keep production scientific memory closed and queue a reviewed lesson in isolated custody. Receipt and exposure authority must precede access so an invalid run cannot disappear. A receipt write permission must not permit editing earlier receipts. Result access is not access to every protected evaluation dataset. Trial registration is not authority to launch it.

Machine statuses distinguish NOT_GRANTED, PROHIBITED, LIMITED_HISTORICAL_PUBLIC and AUDIT_ONLY; none is an implicit grant. A decision should include actor/issuer, authentication, exact hashes, allowed paths, source/time/request/byte limits, expiry, revocation and fail-closed behavior. No boolean in a self-authored artifact proves the issuer or authenticity. No approval is requested now: the evidence package for a real trial is incomplete, and this review's authorized work ends at freeze.
