## 2. Candidate comparison

All four candidates are evaluated against the same amortized information rate: one
new disjoint component requires >=80 entry sessions of *additional*, non-overlapping
calendar exposure, because the >=80-session span is generated by the declared
dependence mechanism (shared SPY/market shocks + formation/ADV/holding overlap), not
by an arbitrary buffer choice.

### A. Longer single registered cohort

Redefine the frozen 252 to a larger entry-session count `N` under the *same* S01-S17
rules (only the entry-count parameter changes, before any outcome).
`G(N) = floor((N-1)/80) + 1`.

| G target | Required N (entry sessions) | Calendar time (approx, 252 sessions/yr) |
|---|---|---|
| 10 | 721 | ~2.9 yr |
| 12 | 881 | ~3.5 yr |
| 20 | 1521 | ~6.0 yr |
| 30 | 2321 | ~9.2 yr |

- Entry-session horizon: N as above (single block).
- Influence span: unchanged, >=80 sessions, per-component.
- Effective independent-unit count: G(N) as above, before issuer-recurrence merges.
- Minimum information guard: G>=G_min (10-20 depending on chosen safety margin).
- Interval method feasible: wild cluster bootstrap at the low end (G~=10-12);
  cluster-robust sandwich / nonparametric cluster bootstrap additionally defensible
  at G>=20.
- Issuer recurrence: still merges components regardless of N; N must be chosen with
  margin above the raw guard to absorb expected merges.
- Shared SPY/market shock: already the generating mechanism for the 80-session span;
  unchanged treatment, no new assumption.
- Q1/Q2 impact: first lawful interval only after the full N-session entry window plus
  final component's 19-session hold + 20-session buffer + reconciliation grace elapse.
- Q3 impact: forward-confirmation clock starts no earlier than that same instant.
- Prospective commitments: one calendar/entry-count/guard freeze before any entry.
- Multiplicity: unchanged — one claim, one look, alpha .05, charged at freeze.
- Persistent operational burden: low — one registration, one long wait, Clock wakes
  only on due events; no new cohort-accumulation bookkeeping.
- Failure/INSUFFICIENT: if realized G (post issuer-recurrence merge) < guard at
  freeze, emit `INSUFFICIENT_CLUSTER_INFORMATION`; no post-hoc N extension.

### B. Multiple prospectively registered cohorts, one predeclared claim/look

Reuse the *exact*, already-frozen 252-entry-session S01-S17 protocol unchanged, run
K times as non-overlapping calendar blocks (next cohort's first entry >=80 sessions
after the prior cohort's last entry, to keep spans disjoint by the same rule used
inside one cohort), pool all resulting components across cohorts, and take exactly
one look at the pooled result under one predeclared claim/alpha-.05 budget.

`sessions(K) = K*252 + (K-1)*80` (gaps between cohorts).

| K | Raw components (<=4/cohort) | Sessions | Calendar time |
|---|---|---|---|
| 3 | <=12 | 916 | ~3.6 yr |
| 4 | <=16 | 1248 | ~5.0 yr |

- Entry-session horizon: 252 per cohort block, repeated.
- Influence span: unchanged; cross-cohort disjointness enforced by the same 80-session
  gap rule as within-cohort spacing.
- Effective independent-unit count: up to 4*K raw, reduced by any cross-cohort issuer
  recurrence (a repeat issuer across cohorts still merges its components — this is
  *not* solved by temporal non-overlap, since issuer-recurrence linkage in §10.4 is
  time-independent).
- Minimum information guard: same G_min as A (10-20), applied to the *pooled*,
  post-merge component count at the final cohort in the accumulation.
- Interval method feasible: same as A at the same realized G.
- Issuer recurrence: explicit residual risk — must budget extra raw components
  (K chosen with margin, e.g. K=3 for a G_min=10 target, K_max=4 predeclared
  fallback) because a repeat issuer can silently reduce pooled G below the raw count.
- Shared SPY/market shock: no new cross-cohort connection by construction (spans are
  disjoint), so this dimension is fully resolved by the gap rule, same as A.
- Q1/Q2 impact: same as A, but reached only after the *stopping cohort* (whichever
  cohort in the predeclared sequence first yields pooled post-merge G>=G_min, or
  K_max if never reached) completes its own tail.
- Q3 impact: same as A.
- Prospective commitments: heavier — K, K_max, the non-overlap gap rule, and the
  "stop on component-count only, never on estimate/effect" rule must all be
  predeclared before the first entry, to keep the accrual outcome-blind (component
  count depends on event/issuer/timing facts only, never on realized T_j, so this
  stopping rule does not consume a second look or tune on outcomes).
- Multiplicity: still one claim, one look, alpha .05 — charged once at the stopping
  cohort's freeze, not per cohort. Requires an explicit accrual-until-guard rule
  distinct from an interim statistical look, documented before entry #0 of cohort 1.
- Persistent operational burden: higher than A — repeated registration/freeze
  bookkeeping per cohort, explicit cross-cohort issuer-merge tracking, an explicit
  accrual/stopping-rule ledger entry distinct from the final look.
- Failure/INSUFFICIENT: if pooled post-merge G < G_min at K_max, emit
  `INSUFFICIENT_CLUSTER_INFORMATION`; no further cohort beyond the predeclared K_max.
- Time-to-evidence is comparable to A at the same G_min (slightly worse, due to
  repeated cohort-boundary gap overhead), and it reuses the already-frozen S01-S17
  arithmetic unchanged rather than re-deriving warm-up/calendar/session-count
  invariants for a new N — a real implementation-simplicity and spec-risk advantage,
  at the cost of extra bookkeeping and residual issuer-recurrence uncertainty that A
  does not have (A's single long window still faces issuer recurrence too, but with
  one accounting pass instead of K).

### C. Legitimately shorter influence span

Only admissible if the narrower span is justified independently of the G=4 finding
(i.e., not chosen because it fixes this problem) and before any outcome. The 80-
session span is derived directly from the declared dependence-generating mechanism
(shared SPY/market shocks and formation/ADV/holding window reuse) in S02/§10.4 — it
is not an arbitrary buffer. Shrinking it requires an independently sourced argument
that this specific mechanism decays faster than 20+20 sessions on each side, which
this review has no independent evidence for and is explicitly barred from inventing
to solve the observed deficit (the S11 reviewer's own scope excludes "shrinking
buffers... after observing the failure"). Reopens frozen S02/S06 rules. **Not
adopted**: no independently sourced justification exists at this time: not a
defensible candidate today, though it remains theoretically available if Blue later
obtains an independent, non-outcome-tuned microstructure argument for a shorter
decay window.

### D. Weaker, externally justified dependence model

Would require an external (not derived from this cohort's own outcomes), citable
bound on cross-component correlation that is *weaker* than "any shared issuer or
overlapping influence span implies dependence," e.g. a published bound on Form-4
event/SPY-shock decorrelation timescales. No such external source was identified in
the material available to this review. **Not adopted**: no currently available
external justification; remains theoretically available if Blue later locates one,
but cannot be manufactured here without outcome-shaped reasoning.

## 4. Preferred design (exact)

```
PREFERRED_COHORT_DESIGN = B: repeated frozen S01-S17 252-entry-session cohorts,
  non-overlapping, pooled under one predeclared claim/look.
```

- **Cohort calendar / entry-session count**: each cohort block is the existing
  frozen 252 entry sessions (indices 0..251 relative to its own activation), unchanged
  S01-S17. Cohort i+1's first entry session must fall >=80 regular sessions after
  cohort i's last entry session (index 251 of cohort i), so no cross-cohort influence
  span can overlap.
- **Registration/freeze instant**: the whole accumulation protocol (K_target=3,
  K_max=4, G_min=10, the non-overlap gap rule, and the component-count-only stopping
  rule) is sealed as one document, digest-bound, before cohort 1's activation — i.e.
  before its 20-session warm-up begins. No parameter in this protocol may change once
  cohort 1 is activated.
- **Influence-span definition**: unchanged from S02/§10.4 — formation/ADV lead
  through scheduled exit, extended 20 regular sessions at each end (>=80 sessions
  total per component), including the existing cross-issuer/cross-cohort connectivity
  rule (shared issuer or resolved corporate predecessor/successor merges components
  regardless of which cohort they came from).
- **Component/block construction**: identical to the existing frozen §10.4 connected-
  component rule, applied to the *union* of crossings across all cohorts accumulated
  so far at the stopping instant (not per-cohort in isolation) — a component may span
  two cohorts only via issuer/corporate recurrence, never via temporal span overlap
  (which is structurally excluded by the >=80-session inter-cohort gap).
- **Minimum information guard**: G_min = 10 pooled, post-merge, positive-exposure
  disjoint components (the literature floor the S11 reviewer identified for wild
  cluster bootstrap, the most permissive established method found applicable in
  principle at small G; MacKinnon & Webb's own examined range is ~6-12, so 10 sits
  inside their examined range rather than at its ragged edge). Additionally require
  `max(component exposure)/A <= 0.10`, unchanged from the existing §10.4 guard.
- **Interval method now made attainable**: wild cluster bootstrap (Rademacher sign-
  flip resampling over pooled components), per Cameron/Gelbach/Miller 2008 and
  MacKinnon & Webb 2018, at the achievable `2^10 = 1024`-point sign-flip support —
  fine enough to resolve a nominal two-sided alpha=.05 tail (`2/1024 ~= 0.002`
  granularity), unlike the G=4 case's 16-point support. If accrual reaches G>=20
  before K_max, the cluster-robust sandwich and nonparametric cluster bootstrap
  additionally become defensible as cross-checks (not required for the primary
  interval).
- **Evidence label before the guard**: `DEVELOPMENT` only; no interval; point ratio
  `sum(a_j T_j)/sum(a_j)` may still be reported as a diagnostic cross-check per
  §10.4's existing "point is diagnostic only" provision.
- **Evidence label after the guard**: eligible for `FORWARD_CONFIRMATION` only if, in
  addition to G>=G_min, all pre-existing §10.5 requirements hold unchanged (unspent
  family budget, qualified/applicable dependence method, complete D19, session-scoped
  forward-admissibility receipts). Reaching G_min is necessary, not sufficient.
- **Repeated-cohort accumulation rule**: activate cohort 1; at its full completion
  (all components' tails and reconciliation grace elapsed), compute pooled post-merge
  G. If G>=10, stop and take the one look. If G<10 and cohorts-so-far < K_max=4,
  activate the next cohort (>=80-session gap enforced) and repeat the pooled-G check
  at its completion. If G<10 after cohort K_max=4 completes, stop accrual and emit
  `INSUFFICIENT_CLUSTER_INFORMATION` — no fifth cohort, no threshold relaxation.
  This check inspects only event/issuer/timing structure, never T_j or the point
  estimate, so it is not a second statistical look.
- **One-look/multiplicity rule**: one claim, one inferential look, family alpha .05,
  charged durably at the stopping cohort's freeze (whichever cohort that is),
  identical in kind to the existing §10.5 rule — the multi-cohort accrual does not
  create additional looks because no estimate or interval is computed or examined
  before the stopping instant.
- **Exact first lawful Q1/Q2 condition**: the stopping cohort (as defined above) has
  fully matured (all its components' 19-session holds + 20-session buffers +
  20-session reconciliation grace elapsed), pooled post-merge G>=10 is confirmed, and
  all pre-existing §10.5 admissibility/use/lineage receipts are present — at that
  instant, and not before, a lawful wild-cluster-bootstrap interval may be computed
  and Q1 (effect exists, lower>0) / Q2 (evidence valid, not `INSUFFICIENT`) become
  answerable rather than structurally blocked.
- **Expected time-to-first-answer**: 3 cohorts (K_target), ~916 entry+gap sessions
  ~= 3.6 calendar years from cohort-1 activation, if issuer recurrence does not merge
  the raw <=12 components below 10; up to ~5.0 years (K_max=4, ~1248 sessions) if a
  4th cohort is needed to clear recurrence losses. This is materially shorter than
  option A's single-cohort G=20+ path (~6+ years) and dramatically shorter than the
  already-rejected G=30 design (~9.2 years), while reusing the frozen protocol
  unmodified.

## 5. Forward confirmation (Q3), other question families

Reaching G_min does not by itself grant `FORWARD_CONFIRMATION` (Q3): it only removes
the current *structural* Q1/Q2 block. §10.5's unrelated requirements (unspent family
budget, session-scoped evidence identity, atom/ancestor consumption checks) remain
fully in force and unchanged by this design. Q4-Q12 are unaffected in kind by this
design; they remain downstream of a lawful Q1/Q2 answer, as in the existing map.

## 6. Deferred limitations

- Issuer-recurrence merge magnitude across real Form-4 issuers is not estimated here
  (no outcome/universe data was inspected); K_target=3 vs K_max=4 is a structural
  margin choice, not a calibrated forecast.
- G>=20/30 cross-check methods, useful partial-identification inference, and
  calibrated real execution/liquidity parameters remain outside this design's scope,
  as in the inherited S01-S17 decisions.
- This design does not itself prove real Form-4 data availability, profitability, or
  that the accrual will complete within the stated calendar bound if genuine event
  scarcity or data gaps extend any single cohort's own D19 completion.
- Options C and D remain theoretically available but are not adopted today for lack
  of independent, non-outcome-tuned justification; a future, separately sourced
  argument for either could shorten this design further without contradicting it.
