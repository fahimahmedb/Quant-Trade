## WHAT_GAP_WAS_PROVEN

The mandatory base retained the current canonical frozen-envelope, trial-ledger and exact replay/binding machinery under `research/research_os`, but `src/quant/factory` no longer contained the historically unique experiment registry, outcome firewall, geometry or power capabilities identified around historical Factory rail `ca8ffe439953b063fb9d049773ce0b6245958c7d`.

The historical implementations were not admissible as-is: the old registry was an in-memory scientific state authority, old geometry inspected realized return vectors, and the old outcome firewall could open outcomes after a Blue gate. Import-exact would therefore duplicate current authority and weaken the present campaign invariants.

## WHAT_CHANGED

- Added a pure immutable experiment-registry binding contract. It persists nothing and therefore cannot become a second truth store.
- Registry identity binds exact candidate, generation, protocol, frozen protocol, source/PIT/code-environment binding hashes, trial accounting, planned geometry and power declarations.
- Added a fail-closed lifecycle limited to `FROZEN -> PREPARED -> RECEIPT_BOUND -> REPLAY_VERIFIED`. No outcome/evaluation lifecycle state exists.
- Added pre-outcome geometry declarations. Historical realized-return geometry is not imported.
- Added power declarations with explicit `UNKNOWN`; numeric declarations reject bool/nonfinite/semantic-null abuse. Normal-approximation sample size is available only from explicitly supplied assumptions and carries no empirical claim.
- Added a recursive pre-outcome firewall that rejects outcome payloads, outcome-derived fields, relaxed authority flags, opened outcome state and nonfinite values while allowing preregistered `outcome_definition` text.
- Preserved the historical outcome API only as a compatibility denial surface: outcome access is always `SEALED_BY_AUTHORITY` and environment tokens confer no authority.
