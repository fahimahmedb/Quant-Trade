# Local visual assets

- Mineral floor: Poly Haven, **concrete_floor_02**, CC0. Color, roughness and OpenGL normal maps, 1K. https://polyhaven.com/a/concrete_floor_02
- Timber: three.js **hardwood2** example textures, retained from https://threejs.org/examples/textures/ (diffuse, bump, roughness); distributed with the MIT-licensed three.js example collection.
- Adult head geometry: original model by **Lee Perry-Smith**, distributed in the three.js example collection at https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/LeePerrySmith . Only cropped position/normal/index geometry is retained locally; no photo texture, identity or worker role is inferred from this visual model. Source distribution MIT license retained under `ui/vendor/THREE-LICENSE.txt`.
- Architecture, furniture, technical instruments, materials, tailored body meshes and all neutral architectural screen illustrations: authored for this laboratory.

All assets are local. They depict a fictional architectural environment, not research evidence. No external texture or model server is contacted by the live page.
