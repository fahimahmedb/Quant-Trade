## Minimal repair and compatibility

The queue compares canonical finite JSON bodies under its existing file lock,
distinguishing bool/int/float values while ignoring key order and whitespace.
A queue-local parser rejects repeated keys at every nesting level, nonfinite
values and existing non-object documents. A missing path remains a legitimate
new queue. V1 root shape is explicitly version/tasks; unknown or missing root
fields are refused rather than silently thrown away. The explicit metadata
object inside each task remains extensible. Existing version/duplicate-task-ID
admission stays in place; this is not an entire new task schema.

Recovery prepares a complete replacement before installing it. It adopts valid
durable readback after conflict or lost ACK. If readback is malformed/unreadable,
it reinstalls the previously observed snapshot and raises; it never rewrites or
"repairs" the invalid file. A real external repair is required before a successful
retry. Valid files retain their wire version, field representation and ordering.
Previously ignored v1 root extensions now require explicit compatible migration.
