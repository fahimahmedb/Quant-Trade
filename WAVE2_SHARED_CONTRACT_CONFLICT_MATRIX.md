## Highest-risk conflict zones

### 1. Scientific eligibility vs operational READY

This is the primary authority seam. `ELIGIBLE_FOR_DISCOVERY`, Candidate qualification and scientific verdicts are scientific states. `READY` is a canonical ResearchTask queue state. Any direct mapping without Control Plane admission is an `AUTHORITY_CONFLICT`.

### 2. Runtime ownership ambiguity already present in base

The repository contains both the modern Research OS Control Plane/task/Oracle contracts and an older `src/autonomous_research` `PersistentQueue`/`ResearchCampaign` scheduler. MEGA E must not add a third scheduler or silently treat the legacy queue as canonical. Canonical convergence needs an explicit ownership/bridge/quarantine decision and regression proof.

### 3. Global runtime truth

`CONTROL_PLANE.json`, `CAPABILITY_REGISTRY.json`, `WORKFLOW_LANES.json`, `RESEARCH_FRONTIER.json`, canonical task/event/receipt contracts, global STATE/status and Live Lab bindings are shared truth. They are not independently ownable by sibling builders. Conflicting sibling edits must be semantically reconciled by canonical Convergence #2 rather than merged mechanically.
