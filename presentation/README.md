# Support de soutenance — mémoire BCE / marchés obligataire & actions

`memoire_soutenance_BdF.pptx` — 24 diapositives, calibrées pour un oral de 20 minutes
(minutage indicatif dans les notes de chaque diapositive).

Contenu : contexte et hypothèses (H1-H5), méthodologie (étude d'événement +
gradient boosting/SHAP + VAR/GARCH), résultats empiriques par hypothèse,
contributions/limites/perspectives — focus sur le fond (finance, méthodologie,
résultats) conformément à la consigne, Python non mis en avant.

Identité visuelle : palette officielle Banque de France (bleu #003DA5 dominant,
cyan #009FDF en repère/secondaire, vert #00B398 réservé aux éléments positifs/validés,
une seule couleur chaude d'accent par diapositive, max 3-4 couleurs visibles par
diapositive), police Calibri (substitut bureautique officiel de Frutiger indiqué
dans le guide). Cartes à bordure fine plutôt qu'ombre portée (rendu plat,
institutionnel), pas d'effets 3D ni de dégradés.

Le logo Banque de France (élément protégé, cf. guide p.4 : « Aucun tiers ne peut
l'utiliser ou le reproduire ») n'a pas été reproduit dans ce support étudiant — la
charte a été suivie via les couleurs, la typographie et les codes de mise en page.
