## WHAT_GAP_WAS_PROVEN

CP003 could distinguish qualified immutable archaeology from review-only history, but a later consumer could still bind a valid source artifact to the wrong canonical memory record. That would preserve source authenticity while corrupting scientific identity. Supersession also needed a narrow bridge from archaeology proof refs to the existing memory supersession contract.

## WHAT_CHANGED

- Added `memory_archaeology_bridge.py` with `bind_qualified_provenance()`.
- Binding is allowed only for `QUALIFIED_CURRENT` findings whose memory action permits canonical use.
- The archaeology `subject_id` must already match canonical memory identity/source-identity fields; there is no fuzzy/branch-name binding.
- Binding only appends immutable archaeology provenance refs.
- Binding explicitly protects `scientific_disposition`, `epistemic_status`, `claim_ceiling`, `evidence`, and semantic `identity` from mutation, then re-validates the canonical memory contract.
- Added `supersession_proof_refs()` so the existing `supersede_with_proof()` flow can consume archaeology refs only when the archaeology finding itself is explicitly `SUPERSEDED_WITH_PROOF` and has immutable proof.
