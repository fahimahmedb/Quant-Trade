# Launch Checklist — Autonomous Codex Run

## Branch

Launch from:

`research/design-v1`

Do not launch from the historical research branch or `codex/test`.

Codex must read:

- `docs/AUTONOMOUS_QUANT_MANDATE.md`
- `docs/MARKET_SELECTION_DOCTRINE.md`

## Launch intent

The run is not a request for one strategy.

It is a request to:

1. reconstruct current research reality;
2. map and rank non-beta-dependent opportunity spaces;
3. choose the best first vertical slice autonomously;
4. build the minimum Alpha Factory components needed for that slice;
5. use them for actual research;
6. preregister material experiments before final evaluation;
7. absorb failed hypotheses internally;
8. continue to the next highest-value action while the environment allows;
9. stop only at a genuine human or resource boundary;
10. leave a clear autonomous next action.

## Human should NOT inject

Do not append a preferred strategy, market, model, indicator or target result to the launch prompt unless intentionally changing the project objective.

The purpose of this run is to observe whether Codex can allocate research effort autonomously under the constitution.

## Expected output

Do not judge the run by the number of commits or by whether the first strategy succeeds.

Judge it by whether:

- it searched beyond repository inertia;
- it allocated research effort rationally;
- it separated alpha from beta;
- it used a real candidate funnel;
- it killed weak ideas without asking the human what to do next;
- it preserved research memory;
- it created at least one end-to-end vertical slice;
- it identified surviving economic evidence honestly;
- it selected its own next action.
