idempotent fills, monotonic marks, detached decision views. North Star §§7,

Starting depth: D1/D2 plus existing end-to-end restart tests; same-process

Defects and localized roots:

1. A failed persistence left `_applied` and accounting ahead of disk; a retry
   silently became a no-op. Save now restores the actual durable document on
   error, handling failure before replacement and acknowledgement loss after it.
2. Atomic replacement admitted stale overwrite of acknowledged fills/marks.
   Save now compares the observed document under a shared file lock and raises
   `LedgerConflict`; the instance refreshes for caller reconsideration/retry.
3. Malformed/nonfinite fills could mutate memory before serialization failed;
   negative prices/costs and empty operation identities were accepted. Validate
   inputs before mutation; restore on arithmetic overflow at serialization.
4. `from_document` advertised a read-only view but could create a persistent
   file; save/fill/mark now reject detached views, and the document is copied.

Adversarial cases: two stale writers released by a barrier; stale mark after
fill; failure before replace; actual subprocess death immediately before/after
replace; post-replace acknowledgement failure; same-object retry; reopened
replay; nonfinite/boolean/zero/negative/empty/malformed inputs; finite-input
overflow; detached alternate mutation paths. No market data or production state.

Repair scope: same JSON schema, optimistic conflict rather than automatic
redecision, existing operation-id replay semantics retained.
