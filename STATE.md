## Architectural state

Quant System V1 is implemented end to end in persistent paper/shadow mode. The planes named in
`SYSTEM_ARCHITECTURE.md` all exist in code, hold persistent state and are connected by the
Control Plane clock rather than by a script that runs them in order.

Package layout mirrors the planes:

| Module | Plane |
| --- | --- |
| `src/quant/clock.py`, `state.py`, `events.py`, `paths.py` | Control Plane |
| `src/quant/dataplane/` | Data Plane |
| `src/quant/factory/` | Research Factory |
| `src/quant/desk/` | Capital Desk |
| `src/quant/book/` | Persistent Book |
| `src/quant/learning/` | Learning / Memory |
| `src/quant/status/` | Status surface and Chief Brief |

The PR #7 and PR #9 primitives are reused rather than replaced: `ResearchTicket` carries research
lifecycle, and `PersistentQueue` / `ResearchTask` are now the Control Plane's durable work queue.

## SEC Form-4 P0 raw capture

`P0_RAW_CAPTURE_OPERATIONAL = TRUE` as of 2026-09-18. The lane has made real SEC requests and the
mission's acceptance criteria are met by recorded evidence, not by assertion:

| Criterion | Live result |
| --- | --- |
| `VALID_DISCOVERY` | TRUE |
| `COVERAGE_STATE` | COMPLETE |
| `HEARTBEAT_DURABLE` | TRUE |
| `RAW_CAPTURE_DURABLE` | TRUE |

The opaque evidence artifact is `handoff/SEC_FORM4_P0_FIRST_LIVE_PROBE_2026-09-18.json`. It carries
attempt/receipt timestamps, content addresses, byte totals, the request controls in force and the
SEC policy sources consulted. It deliberately carries no filing identity, locator, body or count.

What the first live run established: the collector operated below its frozen 2 req/s cap and
SEC's documented 10 req/s ceiling; discovery validated successfully; immutable content-addressed
Form-4 captures are present and passed full address/hash verification; a subsequent poll *earned*
`NO_NEW_DATA` by re-establishing continuity from the cursor without refetching acknowledged work;
and a restart preserved the attempt journal, envelopes, raw bytes, cursor and coverage state.

Design, in one line each:

- **Discovery** is the Latest Filings Ownership/Form-4 Atom feed, one compact request per poll. The
  raw document locator is derived deterministically from the accession, so a filing costs exactly
  one further request and nothing is crawled around it.
- **`NO_NEW_DATA` is earned.** `assert_no_new_data_earned` requires a validated discovery response
  *and* proven continuity. An HTML error page under a nominal 200, an unparseable payload, a form
  filter that cannot be shown to work, or an unaccountable entry are all `DISCOVERY_INVALID`.
- **Coverage is a claim with a proof.** Continuity means the poll walked back to the exact identity
  the last validated poll reached. Everything else is `COVERAGE_UNKNOWN` with the affected
  cursor/page range or day recorded durably. A healthy heartbeat never upgrades coverage.
- **The daily master index is the coverage authority.** Expected Form-4 accessions for a closed day
  are compared against what was captured. Day-1 is honest detection; the backfill engine is later
  work, and a detected gap stays open rather than being explained away.
- **Immutability.** Content-addressed objects linked into place and stored `0o444`; an identical
  re-capture deduplicates; differing bytes under one source identity append an explicit conflict
  version; a truncated transfer is preserved in a separate incomplete namespace and can never be
  promoted to a capture. The hash always describes the bytes that arrived, so the gzip bodies SEC
  actually serves are stored compressed and decoded only on a throwaway copy for parsing.
- **Commit order** is raw bytes, then envelope, then task acknowledgement, then cursor advance. The
  envelope is the acknowledgement, which is what makes each crash boundary replayable.
- **Request policy** is deliberately below the SEC ceiling: 60s poll, concurrency 1, 2 req/s, no
  burst, bounded `5s -> 15s -> 60s -> 5m -> 15m` backoff with jitter, `Retry-After` honoured as a
  floor, extended cooldown on 403, and cooldowns that survive restart. The budget is a file lock, so
  it is global across consumers *on one machine*.
- **Fails closed.** Without `QUANT_SEC_USER_AGENT` carrying a contact address the lane is `BLOCKED`
  and makes no request. The declared identity is supplied at runtime and is not committed.

### Pre-t0 continuity instrumentation

`P0_CONTINUOUS_SERVICE_STATE = OPEN / NOT_YET_PROVEN_CONTINUOUS`. Both frozen
`BLOCKS_CAPTURE_INTEGRITY` blockers are closed, and `t0` is Blue's to declare.

- **`HIDDEN_TRANSPORT_RETRY` — CLOSED.** The nested HTTP retry is removed, and
  `ONE_BUDGET_RESERVATION == ONE_NETWORK_REQUEST_ATTEMPT == ONE_AUDITABLE_ATTEMPT_ID`
  is now structural: `transport.fetch` requires a single-use permit minted from
  one budget reservation and carrying the attempt id, consumed at send, and a
  second send raises. The ordinary stale-keep-alive case is handled by
  reconnecting *before* sending, which emits no extra request.
- **`INCOMPLETE_CRITICAL_POLICY_SERIALIZATION` — CLOSED.** A dedicated canonical
  serialization replaces `to_dict()`. Every `SecAccessPolicy` field carries
  exactly one of three disjoint classifications, checked against
  `dataclasses.fields` at generation time, so an unclassified field blocks
  fingerprint generation rather than escaping it.
- **`ACQUISITION_CRITICAL_FINGERPRINT` materialized.** `sha256(canonical_json(manifest))`
  over module digests, canonical policy, request shape, the classification itself
  and the supervisor manifest. `clock.py` is included in full per the
  conservative V1 rule.
- **Provenance.** Scheduler transitions are written prospectively with
  `next_due_at`, cause, active fingerprint and cooldown state, so the audit never
  infers that nothing was due from the absence of an attempt. Lifecycle cause
  comes from `deploy/quant_sec_supervisor.py`; an absent cause is
  `LIFECYCLE_CAUSE_UNATTESTED`, an explicit gap, never a benign default.

### Blue review of PR #17 — three further defects, closed

Blue reviewed head `d1b164fe` and did not authorize merge or `t0`. Three defects,
all accepted and closed; the audit one was the most serious.

- **`RETROSPECTIVE_AUDIT_CAN_FALSE_PASS` — CLOSED.** The audit meant to prove the
  absence of holes could whitewash a missed deadline, three ways: the attempt
  window was `abs(attempt - due) <= tolerance`, so a request made *before* a
  deadline could prove it was later met; attempts were never consumed, so one
  request could answer several obligations; and *any* later transition counted as
  supersession, including one recorded after the deadline was already missed. All
  three had one root cause — obligations had no identity. They now do:
  one obligation resolves to exactly one resolution, attempt matching is
  forward-only and consumed, and supersession requires a transition that names the
  obligation, was recorded before its due time, and carries an authorized cause.
  A journal whose commitments lack identity fails the window rather than falling
  back to matching by time.
- **`LIFECYCLE_PROVENANCE_NOT_AUTHORITATIVE` — CLOSED.** Absence of
  service-manager provenance now yields `MANUAL_START`, never `SCHEDULED_START`,
  so omitting a flag cannot buy a clean record. A supervisor that dies is detected
  by its own running marker and invocation identity rather than inheriting a clean
  start. Acquisition-critical runtime overrides are refused outright in qualifying
  mode and bound into the fingerprint manifest in any mode, because two services
  from identical code with different cadence are not the same service.
- **`VISIBILITY_FIREWALL_REGRESSION` — CLOSED, exposure irreversible.** The first
  rodage artifact published a FILING request count while asserting it carried no
  filing count; one filing costs one FILING request, so it was a filing count by
  proxy. Blue saw it. It is removed, the invariant is now stated as booleans, and
  the exposure is recorded rather than papered over. Blindness was **not**
  restored and this has no authority over any later scientific decision.

### Blue follow-up on PR #17 — two points, closed

Blue confirmed the three defects fixed and CI green on `1450af4a`, and left two
concrete points. Both are closed, and closing the second exposed a third gap.

- **`SYSTEMD_RESTART_CAUSE_AMBIGUOUS` — CLOSED.** `INVOCATION_ID` proves systemd
  launched the service but not *why*, so `systemctl restart quant-sec-capture`
  typed by a human classified as `SCHEDULED_START` and hid an operator
  intervention behind a non-invalidating cause. An automatic action must now be
  **positively demonstrated**: the only positive reasons a cleanly stopped service
  can start are a host boot — visible because the kernel's boot id changed — and
  the first start of a deployment. A restart after a failure counts as automatic
  only while it is inside the window the unit's `RestartSec` implies; past that
  systemd has given up, so a start is an operator acting on a stopped service.
  Everything else is `MANUAL_START`. Verified live: a clean stop, same host boot,
  new invocation identity was classified `MANUAL_START` and recorded invalidating.
- **`MATERIALIZED_FINGERPRINT_NOT_VERIFIED_AGAINST_ACTIVE` — CLOSED.**
  `t0_readiness()` checked only that the fingerprint file existed, never that it
  described the running build. That is how a stale fingerprint reached a published
  artifact while `visibility.py` — explicitly fingerprint-critical — had changed
  after it was computed. Readiness and telemetry now compare the two and block on
  `FINGERPRINT_MATERIALIZED_MISMATCH`.

  The check immediately earned its keep: a manifest materialized *outside* the
  service environment can never match, because effective service configuration is
  part of the manifest. The supervisor therefore materializes it itself, in the
  child environment, and only when none exists — so an existing manifest is never
  silently re-frozen and a mid-window change still surfaces as a mismatch.

A further gap found while closing those: **`SERVICE_ENTRY_POINT_OUTSIDE_FINGERPRINT`**
(`BLOCKS_CAPTURE_INTEGRITY`). `scripts/quant.py` was not in the frozen membership,
yet its `sec-serve` binds the clock's wake cadence into `system.serve()` and so
decides how often a due poll is noticed — acquisition timing in a file no digest
covered. Added to the membership, and the verification tree digest now covers

Final rodage: `handoff/SEC_FORM4_P0_PRE_T0_RODAGE_FINAL_2026-09-19.json`, run on the

## Current research evidence

**These numbers replace the ones published in the first version of PR #12.** The earlier
metrics were computed on a close(t) -> close(t+1) interval, which credited the overnight gap
between the decision and the earliest possible fill. The corrected timeline is

`information through close(t) -> decision after close(t) -> entry at open(t+1) -> exit at open(t+2)`

and is now shared by the research evaluator, the desk and the Book. The old figures are not
comparable and should not be cited.

Two lanes ran on the new panel. The second was promoted automatically by the first lane's
diagnosis, not by a human supplying the next idea.

Windows: discovery 2016-09-12 to 2022-03-08, validation 2022-03-09 to 2025-03-11, and a shadow
window from 2025-03-12 reserved for the desk and never visible to research.

### Lane 1 - `xs_daily_relative_value`: filtered before validation

Under the corrected timeline the best of its 24 declared expressions reached a discovery Sharpe
of **-0.015**. The lane's own rule is that the validation window is only spent on a candidate
that survived discovery, so the window was preserved rather than consumed. Under the old,
gap-inflated timeline this same family reached +0.20 and was carried all the way to validation.

Its scan still showed the cost mechanism clearly: 10 of 24 expressions were gross-positive and
net-negative, at a median 157x annual turnover. That diagnosis is what promoted lane 2.

### Lane 2 - `xs_execution_aware_relative_value`: rejected out of sample

| Metric | Value |
| --- | --- |
| Expression | `xs_momentum_l21_z0.5_h5_b0.05` |
| Discovery Sharpe | +0.363 |
| OOS net return | **-6.08%** |
| OOS gross return | -1.37% |
| Modelled costs | 4.90% |
| Annual turnover | 32.9x |
| Market beta | -0.062 (benchmark +38.34% over the same interval) |

**No strategy is tradable.** The capital Book has never taken a position.

What the evidence actually says:

1. The daily family does not survive its own discovery window once the return interval starts
   where an order could actually execute. Most of its apparent edge was in the gap.
2. The structural response to cost worked mechanically: turnover 157x -> 33x, modelled costs
   4.9% of the window. It did not rescue the strategy, because out of sample the residual was
   gross-negative as well.
3. Nothing is close to significant. After 36 declared expressions the Bonferroni-adjusted bar is
   t >= 3.20; the best reached -0.39.
4. Beta attribution is reported on every result. |beta| < 0.07 against a benchmark that returned
   +38.3%, so essentially none of the outcome is disguised market exposure.

The honest conclusion is unchanged in direction and stronger in degree: cross-sectional sector
relative value, as expressed here, is not a source of edge on this dataset.

## Known limitations

- Research inference still uses independent-observation t-statistics; HAC/Newey-West or a
  block bootstrap is required before future positive evidence can authorize capital.
- Native ingestion scheduling/event subscriptions remain absent; `serve` discovers refreshes
  by polling. Historical changes inside a frozen research cohort block the lineage for review.
- The SEC traffic budget is a file lock, so it bounds every consumer on one machine but cannot
  coordinate two machines. SEC counts a requester's traffic across all of them, so two collectors
  must not run concurrently until the budget moves behind a shared service.
- SEC capture history begins at its bootstrap point. The discovery feed is a rolling window with no
  beginning, so the first poll defines the scope rather than crawling backwards; filings older than
  that point were never in scope and are the reconciliation/backfill engine's work. Detection of
  such gaps exists; repair does not.
- Captured Form-4 bytes are raw evidence only. There is no parser, no qualification logic and no
  admissibility label, and `SCAN-INSIDER-FILINGS-001` stays scientifically blocked.

- Cash earns no financing return and shorts pay no borrow. Both are modelled as zero and are
  material to a real bankroll.
- The `DECAYING` and `RETIRED` lifecycle transitions are implemented and unit-tested but have
  never fired on real evidence, because no strategy has ever been tradable. The system does not
  yet demonstrate autonomous alpha-decay management; it demonstrates the state machine that
  would carry it.
- Strategy versioning preserves superseded documents in `previous_versions`, so old evidence
  stays inspectable. It is not a full audit log: intermediate edits within one version are not
  retained.
- The evaluation ledger's materiality band is a fixed fraction of initial capital rather than of
  capital actually at risk, so a small counterfactual is reported as UNDETERMINED rather than
  scaled to the exposure that produced it.
- The execution model's spread and impact coefficients are assumed, not calibrated against
  quotes. Costs decided both research results, so this assumption carries real weight.
- Research breadth is one signal family on one asset class. Nothing here supports a conclusion
  about the Research Factory's general ability to find edge.
- The status surface is a text rendering, not an interactive control UI.
- `serve` wakes on a fixed poll interval and re-reads the dataset registry; it does not yet
  subscribe to external events.

## Highest-value next actions

1. **Breadth, not depth.** One signal family on nine ETFs is too narrow a search to conclude
   anything about the Research Factory. The next lane should be structurally independent, not
   another parameterisation of the residual.
2. **Cost realism as a first-class model.** Costs decided both results. The execution model
   should be calibrated against something better than an assumed spread.
3. **A dataset that unblocks a ranked lane.** `factor_residual` is ranked above anything currently
   executable and is blocked purely on data. `insider_filings` is now accumulating raw evidence;
   what it still lacks is the scientific protocol, not the bytes.
4. **Exercise the decay path.** Until a strategy is tradable, `SHADOW -> ACTIVE_SHADOW ->
   DECAYING -> RETIRED` is untested against real evidence.
