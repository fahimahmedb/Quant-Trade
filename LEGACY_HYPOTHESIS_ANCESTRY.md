# Quant-Trade — Legacy Hypothesis Ancestry

Date: 2026-10-15  
Scope: historical reconciliation only. No new economic experiment is authorized or performed by this artifact.

## Ancestry rules used

- **MATERIAL CHANGE**: new generation when horizon, universe, mechanism, target outcome, execution semantics, or evidence regime changes materially.
- **NON-MATERIAL AMENDMENT**: same economic generation when a parser, reader, source-format adapter, documentation or transport repair changes without changing the economic claim or creating new independent observations.
- If the repository does not prove a strict parent-child relationship, this file uses `GENERATION_RELATION = UNCERTAIN` rather than fabricating a clean tree.
- Retrospective work never becomes prospective because a later generation has stricter governance.

**Economic ancestry conclusion:** V1→V4 is a sequence of research-design generations. It is not a sequence of progressively validated economic results. `PROSPECTIVE_VALIDATED = FALSE` throughout the recovered lineage.
